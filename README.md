# CloudNest Platform

## Overview

CloudNest Platform is a cloud-native infrastructure project designed to demonstrate modern Platform Engineering, Infrastructure as Code, Kubernetes orchestration, and AWS cloud deployment practices.

The platform was deployed on Amazon EKS using Terraform and Kubernetes, providing a scalable and automated environment for containerized applications.

## Technologies Used

* AWS
* Amazon EKS
* Terraform
* Kubernetes
* Docker
* Jenkins
* GitHub
* Prometheus
* Grafana

## Features

* Infrastructure provisioning using Terraform
* Kubernetes cluster deployment on AWS EKS
* Containerized application deployment
* Load balancing and networking configuration
* CI/CD integration
* Monitoring and observability
* Infrastructure as Code best practices

## Architecture

GitHub → Jenkins → Docker → Amazon ECR → Amazon EKS → Kubernetes Services → Monitoring (Prometheus/Grafana)

## Project Goals

* Automate infrastructure deployment
* Deploy scalable Kubernetes workloads
* Implement cloud-native architecture
* Demonstrate Platform Engineering concepts
* Improve operational reliability through automation
